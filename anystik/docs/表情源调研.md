## 二、EIF（QQ 表情包）🔧 本期方案：离线重打包 zip

### eif 文件本质

- eif 是 **OLE 复合文档（Compound File Binary / CFBF）**，非 zip
- 结构：根含 `Face.dat` 索引流 + 分组子目录 + 图片流（GIF/PNG/BMP/JPG）
- `Face.dat` 记录分组及组内排序，路径经 **XOR 混淆**，需按字节流找 key 解码
- 传统 QQ（PC 旧架构，现行 9.7.x）可「导出表情包 → eif」；NTQQ 不支持导出
- 除 eif 外 QQ 表情包尚有 `cfc`/`eip` 等历史格式

### 离线解析参考（doc 内附链接）

| 项目 | 语言 | 说明 |
|---|---|---|
| readme9txt/QQEIF-Extractor | Python | 提图并保留分组排序；README 含 bilibili 分析 `cv36661612` |
| statementreply/uneif | C++ | 解包 eif |
| momocow/node-qq-eif | Node | 列出/提取图片（CFBF 流）|
| QL-Win/QuickLook `EifExtractor.cs` | C# | 解析 Face.dat 重命名/重排序提图 |

### 可获取 eif 的站点（需 HTML 二次跳转，不适合直接做内置源）

| 站点 | 可达性 | 说明 |
|---|---|---|
| cr173.com（西西软件园）| ✅ 200 | QQ表情类目 7349+ 条；下载走 `down.asp?id=N` → 302 至 `cz.197942.com/...zip`（实测返回 `application/zip`，如 eiffacejygj.zip=159154B）；内容是 zip/rar **内含 eif**，属 JS 混淆链接 |
| moyanxsw.com | ✅ 200 | eif 包下载页（如新浪微博表情 5.8M），下载面再跳转 |
| downext.com | ⚠️ 000 不稳定 | 新浪微博 QQ 表情包(eif)，时可达时超时 |
| qqbiaoqing.com | ✅ 200 | QQ表情大全站，正访问为逐张图片（见第三节） |

### 重打包落地流程（写入待打包表情包.md 按此推进）

1. 从上述站点下载含 eif 的 zip/rar → 解压定位 `.eif`
2. 用解析工具（看如上任一实现）提图，并按 `Face.dat` 还原分组与排序
3. 去重 → 转码控体积（动图 gif、静态 webp/png，参考 StickerStore 入包缩放）
4. 组新 zip → 上传可直连托管（app 内置 gh-proxy）→ 加 `kBuiltinSource` 条目
5. 全量 GET 实测字节数填 `approxSize`

> 暂不做应用内 eif 解析（当前安装流程仅 `QZipReader` 解析 zip；CFB 解析为中等体量纯 C++ 工作，留待后续）。

## 结论与建议

- **可零改动直接入库**：volpeon.ink 其余 14 包、NaiJi(udongein.xyz) 各包、fedi-emojis 各 zip、olivvybee release
- **需先拆/转**：moule.world（全量包是容器，选角色包或子包）
- **QQ eif**：先离线重打包 zip 再上线（本期方案），工具链已有现成开源实现
- 补齐 eif 支持后再评估应用内 CFB 解析（后续）。
