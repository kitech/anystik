# 待打包表情包

记录「已找到来源、但尚无整包直链 / 尚未上线」的表情包整包清单。
每项打包完成后，按下方【kBuiltinSource 条目格式】在
`anystik/src/stickerstore.cpp` 的 `kBuiltinSources[]` 中新增一行即可上线。

## 打包/上线流程

1. 全量拉取素材（夸克等需登录态，见各条备注）
2. 去重 → 转码统一体积（动图 gif、静态 webp/png，参考 StickerStore 入包缩放）→ 组 zip
3. 上传到可直连的托管地址（app 端 gh-proxy 已内置，走
   `https://gh-proxy.org/https://github.com/<owner>/<repo>/archive/<40位sha>.zip` 或 raw.gz 均兼容）
4. 新增 `kBuiltinSources` 条目并实测全量 GET 字节数填入 `approxSize`

## kBuiltinSource 条目格式

```cpp
{ "名称",
  "https://<托管地址>/<打包文件>.zip",
  实测全量字节数,   // 预告约值；参照现有条目注释
  "https://<预览列表页>" },   // 预览按钮跳转；不需要填 nullptr
```

字段：`name` / `url` / `approxSize` / `previewUrl` / `enabled`。
`enabled` 默认 `true`；未打包完成前可先写 `false`（表情包目录隐藏该行，
不参与残留下载清理与 probe 种子表；`isBuiltinSourcePack` 识别不受影响）。
`kBuiltinSourceCount` 为 sizeof 自动推导，无需改数。
