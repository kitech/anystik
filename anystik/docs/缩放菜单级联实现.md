# 右键菜单「缩放拷贝」悬停级联子菜单实现

主列表右键菜单的「缩放拷贝 ›」改为经典 Qt 式悬停级联子菜单。
本文档梳理实现背景、上游机制约束、三轮返工的根因与最终方案。

## 背景与目标

- 父菜单打开期间保持打开、可交互（QskMenu 原生在 triggered 后 `DeleteOnClose`
  清除自身，故需要单独模拟子菜单）。
- 悬停「缩放拷贝 ›」行 → 子菜单从该项行**右缘**弹出、**行中对齐**；右缘放不下时
  **侧翻到父菜单左侧**。
- 悬停子菜单保持打开；滑过其它父行/空白后延迟关闭（sloppy）；点击子项复制并
  整组收拢；点父子之外整组关闭；触摸无 hover，点按「缩放拷贝 ›」走 triggered 兜底。
- 档位：0.1 / 0.25 / 0.5 / 2.0；toast 文案不变。

## 上游机制约束（QSKinny 0.8.0 源码核对）

- QskMenu **无原生子菜单**（`QskMenu.cpp` 自带 "we do not offer submenus yet. TODO"）；
  0.8.0 公开 `indexAtPosition` / `cellRect`。
- **定位只能靠 `setOrigin`**：`QskMenu::updateResources()`（QskMenu.cpp:313）在每次
  polish 时用 `setOrigin` 存的值**覆盖 setPosition** → 外力 `setPosition` 无效，
  正确姿势是 `setOrigin(父局部坐标)` + `polish()`；相同坐标时用 `qFuzzyCompare`
  跳过重锚，避免每次鼠标移动都触发 polish。
- `triggered` 仅在**同项 press+release** 时发射（mouseReleaseEvent 按
  `indexAtPosition` 判定）；hover 不触发、不改 currentIndex。
- **模态/CloseOnPressOutside 弹窗会生成 `QskInputGrabber`** 抢走全部 hover：
  - `QskMenu` 构造默认 `setModal(true)` + `CloseOnPressOutside`（QskMenu.cpp:73-76）；
    `QskPopup::updateInputGrabber` 只要两者任一为真即创建 grabber。
  - `QskInputGrabber` `setAcceptHoverEvents(true)`（QskInputGrabber.cpp:114）且几何
    **铺满整个页面**，又是叠加在其它同级之上的 popup 的子项 → 全屏最顶层 hover 接收者，
    在自身 popup 之外还拦截 HoverEnter/Leave（event() 返回 true 停止传播）。
  - Qt 只把 hover 发给**最顶层**那个接受 hover 的 item → 子菜单一开，父菜单立即
    HoverLeave 且之后**再无 HoverMove**，任何"进子菜单取消关闭"的防御都永不触发。
- 事件模型结论：需要两个 popup 共存且父菜单继续收 hover 时，**子菜单必须无 grabber**
  （非 modal + 无 CloseOnPressOutside），点击外部关闭用自研 full-page overlay 兜底
  （只吃按下、不抢 hover）。这与 Qt Quick Controls 2（QQuickOverlay 按点路由）、
  Avalonia（OverlayInputPassThroughElement）"子菜单打开时父菜单保留输入"的思路一致。

## 最终方案（第三轮）

改动集中在 `src/stickerhomepage.{h,cpp}`、`src/menuoverlay.{h,cpp}`。

### MenuOverlay（src/menuoverlay.{h,cpp}）

- `MenuOverlay(QskMenu* menu, QskMenu* parentMenu = nullptr)`：透明全页 QQuickItem，
  `setAcceptedMouseButtons(Qt::AllButtons)`，**不** acceptHoverEvents（不抢 hover）。
- `handlePress` 按 `mapFromScene` 三段判定：
  - 落在子菜单内 → 放行；
  - 落在父菜单（parentMenu 非空）内 → 仅 `menu->close()` 并放行事件传导到父菜单项；
  - 两者之外 → `menu->close(); parentMenu->close();`。

### StickerHomePage（src/stickerhomepage.{h,cpp}）

- `showStickerMenu` 记录 `m_ctxMenu`/`m_ctxOverlay`，父菜单装 eventFilter；
  triggered 分支 `idxScaleSub` → `openScaleSub(menu, idxScaleSub)` 并 return
  （**不再无条件 `menu->close()`**）。
- `openScaleSub`：
  - `sub->setModal(false)` + `setPopupFlag(CloseOnPressOutside, false)` +
    `setPopupFlag(DeleteOnClose, false)` —— **关键**：不生成全页 InputGrabber，
    父菜单恢复持续 hover。
  - 打开前用 `sizeConstraint()`（真实 W/H）+ 父 `cellRect` 预锚 `setOrigin`；
    `opened` 时 `applyScaleSubAnchor` 复核（fuzzy 相同则跳过）。
  - 侧翻：右缘放不下 → `X = 父场景左缘 - gap - subW`（完全到父左侧、gap 分隔），
    仅窄窗口钳制含最小覆盖；底部上移钳制。
  - 子菜单 triggered → 复制 + toast 后 `parent->close(); sub->close();`。
  - 子菜单 `closed`：父仍开则恢复 `m_ctxOverlay` 可见；清 `m_scaleSub`。
- `closeScaleSub`：恢复父 overlay；`m_scaleSub` 开则 close；清指针。
- 防抖：`QTimer m_subCloseTimer` 单发 **225ms**（对齐 Qt Quick Controls
  `SUBMENU_DELAY` 与 QMenu sloppy 惯例），timeout → `closeScaleSub()`。
  - `scheduleSubClose()` = timer.start()；`cancelSubClose()` = timer.stop()。
- `eventFilter`（父、子各装，返回 false 不拦截）：
  - 父 `HoverMove`：`idx == 缩放拷贝行` → `cancelSubClose()` + `openScaleSub`（已开则重锚）；
    其它行且子已开 → `scheduleSubClose()`（sloppy 延迟关闭，允许斜向进子菜单）。
  - 父 `HoverLeave` / 子 `HoverLeave` → `scheduleSubClose()`。
  - 子 `HoverEnter`/`HoverMove` → `cancelSubClose()`（保住子菜单）。
- 父菜单 `closed` → 连带 `m_scaleSub->close()`（防点外部残留孤儿），清引用、停计时器。

## 三轮返工记录

### 第一轮（R1）—— 初版级联
父行 HoverMove 开子、HoverLeave 立即关。用户实测问题：子菜单多级反复弹出；
右缘空间不足时子菜单覆盖父菜单。

### 第二轮（R2）—— 定位与防抖
- 定位全改 `setOrigin`（setPosition 被 polish 覆盖的坑）；
- 侧翻公式修正（原先 `anchor.x()-gap-estW` 含了父宽，导致压在父右半区）；
- `singleShot(0)+flag` 改为 150ms `QTimer` 防抖。
仍残留：用户「+2」，悬停反复重弹（开了又关）。

### 第三轮（R3）—— 真根因：InputGrabber 抢 hover
- 根因见上文"上游机制约束"：模态子菜单的 InputGrabber 铺满页面并接受 hover，
  使父菜单收不到 HoverMove，`cancelSubClose` 永不触发 → 225ms 后自动关，
  一动又重开，循环成"反复显示"。坐标/防抖层面的修复全被绕开。
- 修复：子菜单去 grabber（非 modal + 无 CloseOnPressOutside），父菜单恢复 hover，
  sloppy 防抖真正生效；点击关闭由 MenuOverlay 兜底；父关连带子关。
- 修复后桌面验证通过。

## 自检清单

- [x] 悬停「缩放拷贝 ›」行子菜单常驻，不闪关。
- [x] 快速滑过其它父行 / 斜向进入子菜单，225ms 内不被关闭。
- [x] 悬停其它父行静止 >225ms → 子菜单正常收拢。
- [x] 右缘放不下 → 子菜单完整侧翻到父菜单左侧。
- [x] 行中对齐：子菜单首行中线对齐「缩放拷贝 ›」行中线。
- [x] 点击子项 → 复制 + toast，整组关闭。
- [x] 点击父子之外 → 整组关闭。
- [x] 触摸点按「缩放拷贝 ›」→ triggered 兜底打开。
- [x] 父菜单关闭（含点击外部）→ 子菜单连带关闭，无孤儿残留。

## 不做

- 键盘 Esc / 左右箭头跨菜单导航（QskMenu 仅在菜单内处理）。
- 多组子菜单通用框架（当前仅「缩放拷贝」一个子项）。
